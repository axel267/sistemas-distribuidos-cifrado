# sistemas-distribuidos-cifrado
Implementación de un sistema cliente-servidor en Python para la transmisión, encriptación síncrona y verificación de integridad de archivos binarios (imágenes) a través de Sockets TCP

Dependencias y Configuración

Antes de ejecutar los scripts, es necesario instalar las siguientes librerías en el entorno de Python:
pip install pycryptodome

Visualización de imágenes:
pip install pillow
